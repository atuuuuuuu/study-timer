# study-timer

A focus timer in one HTML file: 25 minute focus sessions, 5 minute breaks, a long break every 4th session,
today's totals, keyboard shortcuts, and it keeps exact time even in a background tab.

> **A learning project.** This version was written with [Claude](https://claude.ai) as a reference while I learn
> how apps keep track of time. I'm studying it and rewriting it myself; see [LESSON.md](LESSON.md).

Open `index.html` in a browser. <kbd>Space</kbd> starts and pauses, <kbd>R</kbd> resets.
No install, no internet, nothing leaves your computer.
